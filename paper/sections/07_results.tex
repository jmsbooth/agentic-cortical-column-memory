\section{Results status}

This \releaseversion{} paper does not report a completed registered empirical result. That is a declared publication state rather than a missing table. The registered campaign is pending, and no hypothesis is labelled supported or rejected here.

The repository does include a deterministic software smoke run. Its purpose is to verify that task generation, all requested protocol paths, manifests, provenance traces, resource records, metric generation, and generated table code execute on a clean checkout. Smoke values are not used as evidence for H1--H6 because the adapter is symbolic and intentionally exposes the task structure.

The v1.0 empirical release will replace this section only after all preregistered seeds and task instances are accounted for. It must report raw and processed results, confidence intervals, effect sizes, budget-controlled comparisons, ablations, failure taxonomy, resource Pareto analysis, deviations, and negative findings. Until then, claims in this paper are limited to design decisions, implementation facts, and the registered procedure.
