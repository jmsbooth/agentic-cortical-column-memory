\section{Discussion}

CCM makes a falsifiable systems proposition: some capability failures of a small model may be caused by missing state, missing evidence, or poor coordination rather than only by insufficient parameters. The proposition has two important constraints. First, the architecture must be evaluated against conventional inference scaling. Second, any observed gain may be local to task classes whose information structure matches the explicit memory and action contracts.

The design therefore treats success, calibrated abstention, unresolved disagreement, communication cost, and failure location as first-class outcomes. A system that avoids a confident unsupported answer by abstaining may be preferable to one that wins a forced-choice score, while a system that simply adds calls without improving a budget-controlled frontier is not a useful architectural result.

Several outcomes would be informative. Broad improvement over B0 but not B3 would suggest that coordination is useful while conventional multi-agent inference captures the effect. Improvement over B3 only on memory and active-observation tasks would support a narrower architectural claim. No improvement, or degradation from communication overhead and correlated errors, would be a valid result that constrains the proposal. The protocol is designed to retain each of these outcomes.

The architecture also makes a deliberate departure from the biological inspiration. Its reference frames are typed application state spaces, its columns are software objects around model calls, and its votes are explicit records. These choices improve inspectability and ablation, not biological fidelity.
