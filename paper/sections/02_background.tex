\section{Background and terminology}

\subsection{Thousand Brains Theory and the project implementation}

Hawkins, Ahmad, and Cui describe a theory in which cortical columns learn models of objects and their structure relative to reference frames \citep{hawkins2017columns}. Hawkins et al. later develop a broader framework involving grid-cell-like location representations and object-centric reference frames \citep{hawkins2019framework}. These are theoretical and hypothesis-generating contributions. They are not a specification for language-model agents.

The Thousand Brains Project (TBP) and its Monty implementation are a separate, evolving sensorimotor learning system. Monty is an open-source Python implementation whose current documentation and repository should be cited directly when discussing its capabilities \citep{clay2024tbp,leadholm2026systems}. This paper does not reimplement Monty and does not imply that its mechanisms, TBT, HTM, and CCM are interchangeable.

\subsection{HTM and sparse distributed representations}

Hierarchical Temporal Memory (HTM) is an algorithmic lineage associated with sparse distributed representations (SDRs), sequence memory, and cortical-learning algorithms \citep{ahmad2016sdr,numenta2010htm}. SDRs have a precise representational meaning in that lineage: multiple active components jointly encode a value with sparse distributed activity. A conventional dense or sparse vector embedding is not automatically an SDR. The v0.1.0 CCM implementation uses structured symbolic relations and no embedding; it therefore does not claim an SDR implementation.

\subsection{The engineering analogy}

The mapping in this paper is intentionally one-way. The inspiration suggests modular local models, object- or state-relative representation, multiple partial hypotheses, and active interaction. CCM implements those ideas as data structures and interfaces. It does not assert that the interfaces reproduce neurons, layers, grid cells, or biological learning. Where the analogy stops, the engineering contract begins.
