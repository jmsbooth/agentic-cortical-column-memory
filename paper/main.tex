\begin{abstract}
Persistent memory is an increasingly important component of AI-agent systems, yet common approaches often rely on retained transcripts, summaries, similarity retrieval, or flat episodic records. This paper proposes \ccmname{}, a model-agnostic, agent-internal memory architecture inspired by selected computational principles associated with Thousand Brains Theory. CCM organizes multiple bounded memory/modeling units around structured observations, provenance, temporal history, reference frames, persistent local state, evidence-bearing hypotheses, bounded recall, state reconciliation, and optional active information acquisition. CCM does not model cortical biology and does not claim equivalence between software modules and biological cortical columns. The \releaseversion{} release publishes the architecture, reference implementation, tests, deterministic synthetic validation environments, memory-focused baselines, preregistered hypotheses, and machine-readable manifests before the full empirical campaign is completed. Whether this organization improves memory quality, agent reasoning, or resource efficiency remains an empirical question; model-scale and multi-agent composition are secondary research dimensions.
\end{abstract}

\textbf{Publication state.} The registered experimental campaign has not been completed. This release publishes the architecture, implementation, hypotheses, baselines, metrics, and decision criteria before final data collection. The only executable measurements included at release time are software smoke-test artifacts, clearly labelled as such in the repository.
