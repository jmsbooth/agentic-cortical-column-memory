# Reproduction guide

## Clean checkout

The canonical public repository is:

```bash
git clone https://github.com/jmsbooth/cortical-column-memory.git
cd cortical-column-memory
./scripts/setup
./scripts/run_smoke
./scripts/analyze results/raw/ccm-smoke-v0.1.0.jsonl
python3 scripts/check_smoke.py results/raw/ccm-smoke-v0.1.0.jsonl
python3 -m unittest discover -s tests -t . -v
./scripts/build_paper
```

The smoke path is offline and deterministic at the task/decision level. It uses Python 3.10+ standard-library modules. Wall-clock values are machine-dependent. CPU/GPU utilization, accelerator time, energy, and hosted API cost are recorded as unavailable rather than fabricated.

## Outputs

- `results/manifests/*.json` contains configuration, versions, seed set, hashes, hardware metadata, Git commit, resource fields, and raw-result path.
- `results/raw/*.jsonl` contains one traceable record per task/strategy.
- `results/processed/summary.json` and `summary.csv` are generated from raw records.
- `paper/tables/smoke_summary.tex` is generated by the analysis command.

An output without its manifest is invalid for registered analysis. Do not edit raw records or generated tables by hand.

## Paper build

Run `./scripts/build_paper` after installing Tectonic, TeX Live, or MacTeX. The local path uses bundled Tectonic with retained intermediates so cross-references and the checked-in bibliography resolve across passes, and writes to `paper/build/`. A missing TeX toolchain is an environment limitation, not a reason to alter the manuscript.

## Registered campaign

The frozen configuration is `preregistration/registered-configs/ccm-v0.1.0.json`. `./scripts/run_registered` executes it with the dependency-free adapter. The v0.1.0 protocol is frozen only after this revision; future material changes require a protocol deviation note and version increment.

## Repository rename note

The publication specification establishes `jmsbooth/cortical-column-memory` as canonical. GitHub repository administration is external to this local source revision; until the owner completes the rename, an existing legacy clone may still resolve through `jmsbooth/agentic-cortical-column-memory`.
