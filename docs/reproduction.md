# Reproduction guide

## Clean checkout

```bash
git clone https://github.com/jmsbooth/agentic-cortical-column-memory.git
cd agentic-cortical-column-memory
./scripts/setup
./scripts/run_smoke
./scripts/analyze results/raw/ccm-smoke-v0.1.0.jsonl
```

The smoke path is offline, deterministic at the task/decision level, and uses only Python 3.10+ standard-library modules. Wall-clock values are machine-dependent. CPU/GPU utilization, accelerator time, energy, and hosted API cost are recorded as unavailable rather than fabricated.

## Outputs

- `results/manifests/*.json` contains the complete configuration, versions, seed set, hash, hardware metadata, git commit, and raw-result path.
- `results/raw/*.jsonl` contains one traceable record per task/strategy.
- `results/processed/summary.json` and `summary.csv` are generated from raw records.
- `paper/tables/smoke_summary.tex` is generated by the analysis command.

An output without its manifest is invalid for registered analysis. Do not edit raw records or generated tables by hand.

## Paper build

Run `./scripts/build_paper` after installing Tectonic, TeX Live, or MacTeX. The local path uses Tectonic with retained intermediates so cross-references and the checked-in bibliography are resolved across passes, and writes to `paper/build/`. A missing TeX toolchain is an environment limitation, not a reason to alter the manuscript.

## Registered campaign

The frozen configuration is `preregistration/registered-configs/ccm-v0.1.0.json`. `./scripts/run_registered` executes it with the dependency-free adapter. A future empirical release must preserve the v0.1.0 config and record any deviation before changing hypotheses, metrics, baselines, exclusion rules, or thresholds.
